---
name: Follow-up confirmation phone
description: Required source of phone numbers in follow-up confirmation emails.
---

Follow-up confirmation emails must use the phone number from the current order’s recipient information, not a generic default number or another order’s number.

**Why:** The user explicitly corrected a confirmation that contained an unrelated phone number instead of the recipient-info number.

**How to apply:** Wait for the current order’s recipient information before composing a new confirmation. When the real recipient phone is unavailable, warn rather than substituting a warehouse or company phone.
